# Medyphas AI - Local Setup & Run Instructions

Prototype for Dexathon 2026 (team Codofobia). Demo data only - not medical advice.

## Prerequisites
- Python 3.11
- Node.js 20+ (tested with Node 24)
- Optional: a Gemini API key (https://aistudio.google.com/app/apikey) for document upload, AI explanations,
  read-aloud and the staff assistant. Without it the app still runs (template text, uploads disabled).
- Optional: a Groq API key (https://console.groq.com/keys) as a backup for text explanations.

---

## 1. Backend (`triageai-backend`)

```bash
cd triageai-backend
python3.11 -m venv .venv            # Windows: py -3.11 -m venv .venv  (or: uv venv --python 3.11)
source .venv/bin/activate           # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                # then put your GEMINI_API_KEY in .env (optional)
uvicorn app.main:app --reload --port 8000
```

There is ONE entry point: `app.main:app` (auth, triage, analytics, AI assistant).
The trained model is already in `ml/models/`, so no training is needed.

Check it: http://localhost:8000/api/health  ->  "model_loaded": true
API docs:  http://localhost:8000/docs

Retrain the model (optional):
```bash
python ml/generate_data.py && python ml/train_model.py
```

Run the tests:
```bash
pytest
```

---

## 2. Frontend (`medyphas-ai---intelligence-hub`)

Open a new terminal:
```bash
cd medyphas-ai---intelligence-hub
npm install
cp .env.example .env                # VITE_API_URL=http://localhost:8000
npm run dev
```

App: http://localhost:3000

No API keys go in the frontend. All AI calls go through the backend.

## 5. Deploy

See "Deploy (free tiers)" in README.md: backend on Render (render.yaml Blueprint), frontend on Vercel
(Root Directory medyphas-ai---intelligence-hub, VITE_API_URL = Render URL), then set CORS_ORIGINS on
Render to the Vercel URL.

## Troubleshooting

- Banner "Server offline": the backend isn't running or VITE_API_URL is wrong.
- Banner "Waking up server": the hosted backend (Render free tier) is starting; wait up to a minute.
- Port in use: macOS/Linux `lsof -t -i:8000 | xargs kill -9`;
  Windows `netstat -ano | findstr :8000` then `taskkill /PID <pid> /F`.
- CORS error in the browser: add the frontend URL to CORS_ORIGINS in triageai-backend/.env.
